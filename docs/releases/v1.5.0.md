# VASPBERRY 1.5.0

Released 2026-09-26. This compatible feature release adds a short interface
for repeated Kubo Hall and PROCAR analysis. Keep the scientific choices in
one commented settings file, then calculate and plot with two commands:

```bash
python3 tools/vaspberry_post.py run analysis.ini
python3 tools/vaspberry_post.py plot results/run01
```

Start with the [complete public Bi example](../../examples/features/simple-postprocess/README.md)
and [postprocessing guide](../POSTPROCESSING.md). Build the main Fortran
program using the existing [Intel MPI or alternative compiler instructions](../BUILD.md).
The Python command launches that executable; it is not launched under MPI itself.

## Settings, data and figures

The INI file states the WAVECAR, native executable, MPI ranks, full mesh,
spin convention, energy reference and μ/T scan. Optional sections define
matching PROCAR/OUTCAR, selected bands, atom/orbital groups, spin axis and
reciprocal-space regions. User-written JSON is unnecessary for this route.
Unknown settings are rejected. Relative paths are resolved beside the INI.

The calculation retains `native/PAIRS.csv`, the validated `pairs/` cache,
and `hall/conductivity.csv`, `.dat` and `.npz`. Optional projection adds
`character/` and `character-hall/` tables. Metadata, original settings,
commands and logs remain beside those results. The Fortran output contains
raw interband numerators; the Python numerical stage applies occupations,
energy denominators and integration. The plot stage only reads saved tables.

`run analysis-next.ini --reuse results/run01` recalculates μ/T/region scans
from the same WAVECAR's saved pair cache, skipping native export. `plot`
can redraw results without the original VASP inputs or native executable;
short optional flags select temperature, atom group, map band or σ/Δσ.
Existing outputs are preserved: select fresh result and figure directories.

## Compatibility and validation

Existing commands and numerical output schemas remain available. The
Fortran kernels and underlying integration/projection methods are unchanged;
no numerical migration is needed. The [technical report](../TECHNICAL_REPORT.md)
([PDF](../TECHNICAL_REPORT.pdf)) retains its scientific method edition and
figures. The new guide changes how those calculations are invoked.

The public Bi example demonstrates an insulating T=0 charge-Hall symmetry
check, with all stored bands, and a cached rescan. It does not establish a
converged nonzero response. PROCAR character-weighted charge-Hall attribution
retains the same definition and isolation checks. Canonical momentum,
source-band and k-mesh convergence still require material-specific assessment.

Publication requires all thirteen validation jobs on this exact commit,
including Python regressions, actual native examples, Intel MPI and clean
archive installations. See the [validation record](../VALIDATION_1.5.0.md).
Previous release tags remain unchanged.
