# VASPBERRY 1.5.1 — automatic spinor detection

This patch release simplifies WAVECAR input handling.

VASPBERRY detects scalar or two-component wavefunctions directly from WAVECAR;
routine commands and INI files need no spinor setting.

```bash
make ifx-mpi
mpiexec -n 4 build/vaspberry-ifx-mpi --task kubo \
  --wavecar examples/1H-MoS2/KPATH/2.band/WAVECAR \
  --bands 1:18 --bundle 1 --curvature-csv KUBO.csv
```

This writes the supplied MoS₂ path's occupied-bundle curvature in Å².
For a full Hall scan, follow the [Bi INI example](../../examples/features/simple-postprocess/)
and [postprocessing guide](../POSTPROCESSING.md).

## Compatibility

- Existing `-s 1|2`, `--spinor 1|2` and Python component arguments remain
  optional assertions; a mismatch with WAVECAR is rejected.
- Detection checks all k points and spin channels. Unsupported or inconsistent
  full-complex layouts fail before calculation; reduced Gamma-only files remain
  unsupported.
- The INI `spin_mode` defaults to `auto`; an ISPIN=2 input still requires
  `collinear-up` or `collinear-down` to choose the analyzed channel.
- Two components do not establish that SOC was enabled. `soc` remains a
  compatibility alias for `spinor`; PROCAR spin-frame information still comes
  from the matching OUTCAR.
- The Bi Z₂ comparator explicitly accepts the reviewed 1.5.1 producer and
  continues to reject unreviewed versions. Scientific formulas and saved-result
  schemas are unchanged.

This release retains the clarified VASPBERRY execution commands, reusable pair
cache, MPI-help fix and public-input fetch retries. See the
[changelog](../../CHANGELOG.md), [build guide](../BUILD.md),
[hands-on commands](../HANDS_ON.md) and [validation scope](../VALIDATION_1.5.1.md).
