# VASPBERRY 1.6.2 — native topic help and clearer guides

VASPBERRY 1.6.2 makes the native executable easier to learn: a short overview
leads to help for one calculation or option. Existing calculation commands,
numerical methods and output formats remain compatible.

## Find a calculation, then run it

Download the [versioned source](https://github.com/Infant83/VASPBERRY/releases/tag/v1.6.2)
and start in the extracted repository root. On a Linux host with Intel oneAPI
Fortran, oneMKL and Intel MPI, use the site's setup script or modules:

```bash
source /opt/intel/oneapi/setvars.sh
make ifx-mpi
vb_bin="$PWD/build/vaspberry-ifx-mpi"
mpiexec -n 4 "$vb_bin" --help
mpiexec -n 4 "$vb_bin" --help task
mpiexec -n 4 "$vb_bin" --help kubo
mpiexec -n 4 "$vb_bin" --help bands
```

Use the matching MPI launcher and the number of ranks allowed by your
allocation. Intel Classic and GNU alternatives are in the [build guide](../BUILD.md).
Help is part of the compiled Fortran executable: it prints to the terminal,
requires no Python or material input, and creates no calculation files.

`--help task` lists the calculations; a task page explains its inputs, outputs
and a command to run. `--help options` lists option topics. Try
`--help spin-chern`, `--help mesh` or `--help --bands` as needed. `-h` accepts
the same topics. `--help all` and `--help legacy` show the same complete flag
reference. Run help separately from calculation arguments.

For a first calculation, use the supplied MoS₂ path WAVECAR:

```bash
mkdir -p results/mos2-path
mpiexec -n 4 "$vb_bin" --task kubo \
  --wavecar examples/1H-MoS2/KPATH/2.band/WAVECAR \
  --bands 1:18 --bundle 1 --curvature-csv results/mos2-path/KUBO.csv
```

The input supplies the wavefunctions, eigenvalues, lattice and k points.
The native program writes 48 occupied-bundle curvature rows to `KUBO.csv`:
`spin,k_index,kx_frac,ky_frac,kz_frac,omega_z_A2,min_external_gap_eV`.
Curvature is in Å² and the external-band gap is in eV. Skip `#` metadata lines
when importing the CSV and plot `omega_z_A2` against `k_index` with your
preferred plotting program. Python is optional for this plot. This input is
a path; a full-zone integral requires a full mesh. Use a fresh output path
for each repeat.

## Documentation and compatibility

The guides distinguish Chern numbers from the Fukui–Hatsugai–Suzuki (FHS)
method, also called the Fukui method, used to compute them. The separate
Fukui–Hatsugai (FH) construction supplies the Z₂ invariant. Kubo-formula
curvature and response retain their existing definitions and conventions.
The technical report includes author affiliations, a present-address note and
visible links to commands and data. It remains the **1.6.1 method baseline**;
this patch does not change its calculations or saved reference results.

The native build now also requires `vaspberry_help.inc` beside `vaspberry.f`
and the two spin include files. Source archives contain these build inputs.
Existing task names, short flags, CSV schemas and postprocessing commands
remain supported. Saved outputs retain the versions and checksums of their
original producers.
