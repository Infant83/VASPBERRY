# VASPBERRY 1.6.1 — native projected-spin sectors

VASPBERRY 1.6.1 adds projected-spin Chern numbers and spin-sector Kubo
curvature directly from ordinary two-component VASP `WAVECAR` files.
The matching `OUTCAR` supplies the Cartesian spin frame. Existing native
tasks, automatic spinor detection and postprocessing commands remain supported.

## What is new

- `--task spin-chern` splits an isolated selected band space using the full
  projected-spin matrix and evaluates the two sectors with Fukui determinant
  links. It writes both Chern numbers, their sum and half-difference, plaquette
  fluxes and the projected-spin spectrum.
- `--task spin-kubo` calculates all three Cartesian components of sector
  curvature at arbitrary source k points, including a symmetry path. It
  includes the changing spin-sector basis. An explicit `--mesh NX,NY` adds
  a validated full-mesh approximation integral; the result remains unrounded.
- `spin-kubo --sum-bands N` changes the intermediate-state sum on the same
  stored eigenstates. Source `NBANDS` and the retained sum are recorded
  separately; an unresolved degeneracy at the cutoff is rejected.
- Public graphene and Bi examples provide ordinary VASP preparation,
  Intel Fortran/MPI execution, saved native CSVs, optional plotting, and
  separate sampling, source-state and intermediate-band checks.

## Run the new tasks

Build from the repository root in the matching Intel oneAPI environment:

```bash
source /opt/intel/oneapi/setvars.sh
make ifx-mpi
vb_bin="$PWD/build/vaspberry-ifx-mpi"
```

In a directory containing matching full-mesh `WAVECAR` and `OUTCAR`, run:

```bash
mpiexec -n 4 "$vb_bin" --task spin-chern --bands 1:10 --mesh 12,12
mpiexec -n 4 "$vb_bin" --task spin-kubo --bands 1:10 --mesh 12,12
```

Here `1:10` is the Bi occupied-space example. Choose the bands and mesh of
your calculation; graphene uses occupied bands `1:8`. The default analysis
axis is Cartesian `z`. For a path, omit `--mesh`; for another intermediate
sum, add `--sum-bands N` to `spin-kubo`. Use a fresh directory or a different
`--output NAME` for each repeat. Intel Classic and GNU alternatives are in
the [build guide](../BUILD.md).

The first command writes `SPIN_CHERN.csv`, `SPIN_BERRY.csv` and
`SPIN_SPECTRUM.csv`. The second writes `SPIN_KUBO.csv`,
`SPIN_KUBO_SPECTRUM.csv` and, with explicit mesh input,
`SPIN_KUBO_INTEGRAL.csv`. The native VASPBERRY Fortran/MPI executable performs these calculations;
Python is optional for plotting the finished CSVs. Other programs can read the tables
after skipping `#` metadata lines. Point curvature is in Å², plaquette flux
is in radians, and the Chern values/integrals are dimensionless.

## Examples and interpretation

- [Graphene spin Chern](../../examples/materials/graphene-spin-chern/):
  intrinsic SOC, occupied spin sectors, mesh comparisons and a gap-closed
  control; saved tables can be plotted without rerunning VASP.
- [Graphene path and mesh](../../examples/materials/graphene-spin-chern/kubo/)
  and [local sampling controls](../../examples/materials/graphene-spin-chern/kubo/convergence/):
  resolve a tiny-gap curvature peak and compare local quadrature with
  geometric overlap flux. The local windows do not cover the whole BZ.
- [Bi occupied and selected-pair sectors](../../examples/materials/bi-spin-hall/spin-chern-kubo/)
  and [convergence controls](../../examples/materials/bi-spin-hall/spin-chern-kubo/convergence/):
  compare different projectors and vary mesh, source states and retained
  intermediate bands separately.

Spin-Chern uses the pseudo-wavefunction Gram metric and geometric links.
Spin-Kubo uses a canonical-momentum derivative approximation; its raw integral
is not a certified Chern number or a claim of converged full-BZ response.
These projected-spin quantities are distinct from conventional spin-current
Hall conductivity and PROCAR-weighted charge attribution. Historical reference
files keep their generating versions and measured values.
