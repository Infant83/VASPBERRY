# VASPBERRY 1.3.0 — Kubo transport, spin Hall and optical workflows

**Source release: 25 September 2026.** The immutable `v1.3.0` tag fixes the
code, documentation and reference examples for this version. The default
branch, `master`, contains the current source. Build executables locally.

## Download and start

For the current default branch:

```bash
git clone https://github.com/Infant83/VASPBERRY.git
cd VASPBERRY
```

For reproducible version 1.3.0 calculations:

```bash
git clone --branch v1.3.0 --single-branch https://github.com/Infant83/VASPBERRY.git VASPBERRY-1.3.0
cd VASPBERRY-1.3.0
make serial
python3 -m pip install -r requirements-transport.txt
python3 tools/vaspberry_kubo.py --version
```

The release page also supplies source ZIP and tar archives. The historical
Bi WAVECAR is a Git LFS object; archives may contain its pointer. Fetch the
actual input with `python3 examples/fetch_inputs.py bi --output-dir results/inputs/bi`,
or follow the [input guide](../../examples/INPUTS.md). Licensed VASP POTCAR
files are supplied locally by the user.

## Main changes

- **Kubo curvature and charge Hall:** occupied-bundle curvature, native
  serial/MPI interband-pair export, and occupation-weighted integration.
  `wavecar-hall` combines export and integration; `pair-hall` reuses cached
  data for chemical-potential, temperature and reciprocal-region scans.
  Stored VASP bands and the retained intermediate-band cutoff are separate.
- **PAW optical and current inputs:** `waveder-optics` evaluates complete-group
  circular strengths using standard unmodified VASP optical files.
  `waveder-hall` supports insulating T=0 charge response from those files.
  Optional `velocity-pairs` converts audited full PAW velocities to reusable
  charge pairs. The MoS₂ comparison uses identical VASP states for ordinary
  WAVECAR and full-velocity results; extra producer instructions are separate.
- **Spin Hall and topology:** full complex PAW spin/velocity input, compatible
  chunk assembly, and conventional insulating T=0 `spin-hall`. A fresh Bi
  example combines occupied Z₂=1 and C=0 checks with spin-response convergence
  studies. Its ideal Wannier strip supports the bulk topology interpretation.
- **VASP-derived Wannier response:** `wannier-import`, `wannier-bands` and
  `wannier-hall` retain the Hamiltonian and position operators, including the
  full J0/J1/J2 charge response. The magnetic MnBi₂Te₄ example compares the
  calculated result with independent postw90 output.
- **Actual VASP examples:** MoS₂ Fukui/Kubo maps, symmetry paths, isolated-band
  curvature, Hall scans, real-space states, and a compact monolayer/1H/2H/3R
  optical comparison. Inputs, commands, normalized outputs and figure scripts
  accompany the [scientific report](../TECHNICAL_REPORT.md)
  ([PDF](../TECHNICAL_REPORT.pdf)).
- **Reusable outputs:** selectable CSV/DAT/NPZ numerical tables and PNG/PDF/SVG
  plots, with explicit units, operator scope, validity and input provenance.
- **Normalization correction:** the legacy Fortran Kubo factor of two is fixed.
  Read the [migration guide](../MIGRATION.md) before comparing older values.
  Existing Fukui and Z₂ interfaces retain their geometric interpretation.

## Validation and scientific scope

The scientific source merged in PR26 passed
[main CI](https://github.com/Infant83/VASPBERRY/actions/runs/36099945120) and
[actual Bi serial/MPI validation](https://github.com/Infant83/VASPBERRY/actions/runs/36099945091).
All nine jobs succeeded. Hosted Python 3.10/3.12 each ran 453 tests with two
MPI-dependent skips; separate GNU/OpenMPI jobs passed. The local suite ran
all 453 tests without skips. Intel ifx/ifort compile/help checks passed;
Intel numerical and MPI validation remain the user's responsibility.

Release preparation changes only documentation, version metadata, PDF links
and publication machinery. Publication checks that scientific sources and
reference data match the validated source, and waits for CI on the release
commit. The release's publication record links that exact commit and its CI.
Independent public-only replay reproduced 12 new Hall files and four figures
byte for byte; the [validation record](../VALIDATION_1.3.0.md) gives the wider
numerical checks and historical evidence.

These examples demonstrate software capabilities. Fixed structures and
finite samplings do not establish complete material convergence. In
particular, the Bi spin Hall 12×12→18×18 change is 6.75%; it is not k converged.
The MoS₂ stacking optical results are independent-particle transition
properties, without excitons or photoluminescence predictions.

Ordinary WAVECAR charge calculations use canonical momentum. Optional PAW
operators include additional supported terms, but do not remove k/band
convergence requirements. Conventional spin Hall response is generally not
quantized under SOC and differs from Z₂. The present spin and Wannier Hall
routes require an insulating 2D occupied bundle at T=0. See the
[operator guide](../OPERATOR_ROUTES.md) before selecting a route.
