# VASPBERRY 1.3.0 — general Kubo and charge Hall tools

**Status: unreleased source candidate.** These notes describe the local source
version, not a published tag, GitHub Release, binary archive or DOI. Record the
exact commit used for a calculation.

See the [local validation record](../VALIDATION_1.3.0.md) for the final test
scope and historical-result comparisons.

## Changes

- A general matrix-to-curvature command with explicit output and intermediate
  band windows, physical-operator metadata and numerical checks.
- A standardized point-curvature NPZ/JSON pair with sign, units, coordinates,
  weights, energies, band IDs and provenance.
- An explicit legacy normalization importer and a two-dimensional intrinsic
  charge Hall command with user-defined reciprocal-space regions.
- A public analytic model demonstration requiring no VASP calculation or
  proprietary material files, with a standalone standardized-CSV plotting example.
- The legacy Fortran Kubo factor-of-two normalization fix. Existing Fukui
  and Z2 workflows retain their interface and geometric interpretation.

The [feature examples](../../examples/README.md) provide input files, runnable
workflows and compact numerical/figure references for each calculation feature.
The [material catalog](../../examples/materials/) preserves the existing MoS₂/Bi
paths and describes which inputs are available.

## Getting started and migrating

Install the Python dependencies from the repository checkout:

```bash
python3 -m pip install -r requirements-transport.txt
python3 tools/vaspberry_kubo.py --help
python3 tools/vaspberry_kubo.py --version
```

Use the [Kubo/Hall guide](../KUBO_TRANSPORT.md) for calculations, the
[output specification](../OUTPUT_FORMAT.md) for interchange data, and the
[migration guide](../MIGRATION.md) before comparing historical Kubo results.
Fortran build commands remain in the [build guide](../BUILD.md).

## Validation boundary

The public analytic demonstration and regression checks exercise numerical
formulas, sign, units, metadata and input rejection. They do not validate a
material-specific PAW/nonlocal/SOC/+U exporter or establish that a user's k
mesh and intermediate-band cutoff are converged. Read the command diagnostics
and preserve source provenance.

The new Hall interface reports a 2D intrinsic charge sheet response in
`e²/h`. It makes no spin Hall or 3D bulk-conductivity claim. It does not
relabel a Fukui plaquette flux as point curvature or enforce a Chern integer
by rounding.

Existing 1.2.0 CI and example records remain historical evidence for that
release. They are not presented as a successful 1.3.0 CI run. Local validation
of this candidate must be reported with its own commands, source hashes and
exit status.
