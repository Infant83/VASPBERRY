## Changes

- VASPBERRY-owned full-connection Wannier transport: `wannier-import` validates
  paired Hamiltonian/position matrices, `wannier-bands` computes their dispersion
  and `wannier-hall` integrates the occupied J0/J1/J2 trace. These use NumPy;
  no external response solver is invoked. The actual MnBi₂Te₄ tutorial uses
  this route, with the separately retained postw90 output as an independent check.
  See [the input, formula and resource guide](../WANNIER_TRANSPORT.md).

- A WAVECAR-to-Kubo-Hall workflow with native serial/MPI pair export and
  occupation-weighted Python integration. `wavecar-hall` runs both stages;
  `pair-hall` reuses saved data for μ/T scans. `bundle-hall` handles fixed
  insulating bundles at T=0.
- Selectable CSV, DAT and NPZ Hall tables with JSON conditions, and a common
  plot command producing PNG, PDF or SVG from any numerical format.
- A separate intermediate-band cutoff, `--pair-band-max`, for convergence
  studies using extra stored empty states. Both the source `NBANDS` and
  retained Kubo window remain visible in output metadata.
- Standard VASP 5.4.4 longitudinal PAW optical input through `waveder-hall`,
  restricted to a fixed occupied bundle and T=0 chemical potentials inside
  the common insulating gap. Source, operator and gap checks are explicit.
- A real MoS₂ transport example with a μ/T scan, separate k-mesh and
  intermediate-band studies, matching CSV/DAT/NPZ references, and band/response
  figures. The final 24×24 → 36×36 change is 1.482%; joint convergence is not
  claimed.
- A 21-atom, three-layer MnBi₂Te₄ example with actual VASP preparation files,
  a public SCF density, magnetic Chern and optical integration checks, and a
  separately identified Wannier reference.
- Native `-kubo_bundle 1` evaluates the trace curvature of bands `-ii:-if`,
  canceling internal transitions analytically. Internal degeneracies are
  allowed; external gaps must exceed 1e-5 eV at every sampled spin/k point.
  Serial and MPI runs write a separate bundle CSV through `-kubo_csv`.
  The existing band-resolved mode remains the default.
- A full-zone MoS₂ Fukui curvature tutorial with a new 12×12 SOC VASP
  calculation, Cartesian first-BZ maps and a scientific technical report.
  Berry-curvature figures use physical reciprocal coordinates; the Bi Z₂
  n-field is displayed on its reduced-coordinate mesh. PNG and PDF figures
  are supplied.
- A general matrix-to-curvature command with explicit output and intermediate
  band windows, physical-operator metadata and numerical checks.
- A standardized point-curvature NPZ/JSON pair with sign, units, coordinates,
  weights, energies, band IDs and provenance.
- An explicit legacy normalization importer and a two-dimensional intrinsic
  charge Hall command with user-defined reciprocal-space regions.
- User tutorials using actual public Bi/MoS2 VASP outputs, production
  commands, checked numerical/figure references and application guidance.
  Analytic/synthetic developer checks are retained in validation/models/.
- The legacy Fortran Kubo factor-of-two normalization fix. Existing Fukui
  and Z2 workflows retain their interface and geometric interpretation.

The [feature examples](../../examples/README.md) provide input files, runnable

The [material catalog](../../examples/materials/) preserves the existing MoS₂/Bi
paths and adds the magnetic-film preparation guide, with the available inputs

## Getting started and migrating

Install the Python dependencies from the repository checkout:

```bash
python3 -m pip install -r requirements-transport.txt
python3 tools/vaspberry_kubo.py --help
python3 tools/vaspberry_kubo.py --version
```

Use the [Kubo/Hall guide](../KUBO_TRANSPORT.md) for calculations, the
[output specification](../OUTPUT_FORMAT.md) for interchange data, and the
[migration guide](../MIGRATION.md) before comparing historical Kubo results.
Fortran build commands remain in the [build guide](../BUILD.md).

## Validation boundary

The public analytic demonstration and regression checks exercise numerical
formulas, sign, units, metadata and input rejection. They do not validate a
material-specific PAW/nonlocal/SOC/+U exporter or establish that a user's k
mesh and intermediate-band cutoff are converged. Read the command diagnostics
and preserve source provenance.

The charge Hall interface reports a 2D intrinsic charge sheet response in
`e²/h`. The separate [spin Hall interface](../SPIN_HALL.md) reports the
conventional insulating T=0 spin sheet response in `(ħ/e)(e²/h)`, with
explicit PAW and finite-band current-product conditions. No 3D bulk
conversion is inferred. These commands do not
relabel a Fukui plaquette flux as point curvature or enforce a Chern integer
by rounding.

Existing 1.2.0 CI and example records remain historical evidence for that
release. They are not presented as a successful 1.3.0 CI run. Local validation
of this candidate must be reported with its own commands, calculation settings and
results.
