# VASPBERRY 1.6.6 — report reproduction and CLI consistency

This patch retains the WAVEDER-default charge-Kubo protocol introduced in
1.6.5 and makes commands, input validation, examples and report statements
consistent. The scientific kernels and principal Chern/Kubo reference
results are unchanged.

This is the locally prepared 1.6.6 source update. Publication and remote CI
status are separate from local validation; no new GitHub tag is implied by
this document.

## Command and workflow fixes

- Reject wavefunction, optical and folding options that a standard WAVEDER
  Kubo task does not use; warn when a later band selector overrides an earlier
  one. Keep native `--mesh` integration separate from legacy mesh settings.
- Align CLI and INI chemical-potential scans: equal endpoints require one
  point, and multi-point scans require increasing endpoints. Reject a
  nondefault `--mu-chunk` for the WAVEDER path, where it has no effect.
- Explain that INI `check` evaluates the requested WAVEDER response without
  writing results; show resolved optical files and distinguish these checks
  from material convergence. Correct output names, rescan/cache guidance,
  protocol links and the two-endpoint pair-band cutoff description.
- Stabilize the Intel MPI CI launcher's signal policy for fatal-input tests.
  Controlled exit status, expected diagnostics and output guards remain
  required; native calculations and numerical comparisons are unchanged.

The [standard protocol](../WAVEDER_KUBO_PROTOCOL.md) remains the same. For
supported charge-Kubo calculations, keep matching WAVEDER, WAVECAR, INCAR
and OUTCAR from the same optical run. `--input-dir DIR` selects their directory;
its default is the working directory. A per-file override affects only that
file. The canonical WAVECAR approximation requires `--kubo-source wavecar`.
Other task and operator routes retain their own documented inputs.

## Report and reference corrections

The VASPBERRY and associated analysis calculations behind all sixteen report
figures, Section 3.6 and five numerical result tables were repeated from
retained inputs. Numerical contents in 42 MoS₂ and 63 native topology/spin
CSV tables matched their references exactly. Fixed Wannier-model analyses
and all five MnBi₂Te₄ Hall quadratures were rerun; one independent postw90
quadrature was also repeated. Other external reference points retain their
historical provenance.

Eight supplementary conditioning cells in four Bi rows now use their actual
48-band source instead of a 64-band fallback. Main Chern/Kubo results and
Figure 12 are unchanged. Two rounded report values now use approximate
wording, and the Figure 2 operator label is fully visible. See the
[dated Bi correction](../../examples/materials/bi-spin-hall/spin-chern-kubo/convergence/#reference-diagnostic-correction-2026-10-04),
[report Appendix C](../TECHNICAL_REPORT.md#appendix-c-numerical-reproduction-check-of-2026-10-04),
[PDF](../TECHNICAL_REPORT.pdf), and
[reproduction guide](../../examples/REPORT_REPRODUCTION.md).

## Validation and scope

The [validation record](../VALIDATION_1.6.6.md) separates the report recheck
from exact-commit release testing. Reproduction used retained VASP outputs,
operator matrices and fixed Wannier models; it did not regenerate VASP
SCF/NSCF states, rerun operator production or relocalize Wannier functions.
Existing unresolved mesh, band-window and operator limits remain.
Historical producer versions and earlier release tags are preserved.
