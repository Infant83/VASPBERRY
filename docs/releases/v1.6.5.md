# VASPBERRY 1.6.5 — WAVEDER as the standard Kubo input

This version changes the default Kubo input to the standard VASP WAVEDER
optical matrix. The WAVECAR canonical-momentum approximation remains
available through the explicit `--kubo-source wavecar` selection and emits
an approximation warning. A missing, invalid or unsupported WAVEDER input
never silently selects another operator.

This is the locally prepared 1.6.5 source update. Publication and remote CI
status are separate from local validation; no new GitHub tag is implied by
this document.

This release supersedes the unpublished 1.6.4 candidate. The changes below
are relative to the last published release, 1.6.3. Historical numerical
reference files retain their original operator and producer versions.

## Explicit source directory

Use native or Python `kubo-hall --input-dir DIR` to select the source
directory; the default is the invocation working directory. Each file option
overrides only that named file. `--wavecar` never redirects auxiliary inputs.
Relative CLI and output paths remain relative to the invocation working
directory. INI `input_dir` defaults to that same working directory, while
explicit relative INI paths remain relative to the INI file. The optional
`wavecar` setting overrides only WAVECAR. `--run-dir` remains a mutually
exclusive compatibility alternative for optical chunks; `optical_run_dir`
is a WAVEDER-only INI alias, mutually exclusive with `input_dir`.
This directory policy does not make WAVEDER mandatory for unrelated tasks.

## Standard calculation

Prepare a completed standard VASP 5.4.4 optical calculation and preserve its
WAVEDER, WAVECAR, INCAR and OUTCAR together. The supported standard optical configuration uses
`LOPTICS=.TRUE.`, `LPEAD=.FALSE.`, `LNABLA=.FALSE.`, `LREAL=.FALSE.`,
`ISYM=-1` and `NSW=0`. The matrix may be rectangular: the complete occupied
ket to stored empty bra block is sufficient for the supported occupied-bundle
trace. PAW terms and the optical energy denominator enter VASP's matrix
construction before WAVEDER is written; VASPBERRY does not add them again.

Native `--bands` accepts a single band, range or comma-separated list; its
geometric trace retains all source intermediate bands. `--per-band 1` gives
separate resolvable states. Explicit selected mesh integrals use unit weights
and are not labeled total physical Hall. Omit native `--bands` to retain the
validated insulating occupied-input route.

Python `kubo-hall --bands` supports μ/T-weighted selected contributions;
`--occupied N` keeps the mutually exclusive insulating T=0 contract. INI
`[hall] bands` uses the same selector. Required pairs must exist in at least
one orientation. Complete producer-degenerate groups with equal weights are
allowed; unequal weights inside erased groups or missing required high-band
pairs stop the calculation. Finite temperature never changes a selected
subset into a certified total AHC. Pair-cache export and spin-sector/current
requests retain their separate operator contracts.

## Migration

Commands that intentionally reproduce the old canonical-momentum calculation
must add `--kubo-source wavecar`. The selection is recorded and warns that
PAW/nonlocal/SOC velocity terms are not provided by that approximation.
Existing reference arrays retain their original operator and producer labels.
They are not relabeled as new PAW calculations.

Python settings use `kubo_source = waveder` by default and route supported
charge-Hall jobs through the validated optical adapter. Use an explicit
`kubo_source = wavecar` only for the approximation. Direct full-velocity,
spin-current and Wannier inputs retain their own explicit contracts.

The maintainer selected the 1.6.5 patch-number increment for this update. Its changed
default requires migration: previous implicit WAVECAR Kubo commands
now require an explicit source choice.

## Validation and limits

The [validation record](../VALIDATION_1.6.5.md) distinguishes executed local
checks from unexecuted remote/compiler checks. File/branch validation is
not proof of complete SOC/+U physical velocity or material convergence.
The current full-velocity/spin producer's Hubbard-U exclusion remains in
force. No arbitrary square-matrix padding is introduced.
