# VASPBERRY 1.4.1

Released 2026-09-26. This compatible patch makes the Intel MPI workflow
explicit and connects every numerical output to its subsequent analysis.
The v1.4.0 functionality is already merged into the default `master` branch;
this release includes the following refinements.

## Compile and run with Intel MPI

```bash
source /opt/intel/oneapi/setvars.sh
make ifx-mpi
make check-ifx-mpi
mpiexec -n 4 build/vaspberry-ifx-mpi --task kubo \
  --wavecar examples/1H-MoS2/KPATH/2.band/WAVECAR \
  --spinor 2 --bands 1:18 --bundle 1 --curvature-csv KUBO.csv
```

Use the site's equivalent modules when oneAPI is installed elsewhere.
`mpiifx` and its Intel MPI launcher must come from the same environment.
Intel Classic uses `make ifort-mpi`, `make check-ifort-mpi` and
`build/vaspberry-ifort-mpi`. See the [build guide](../BUILD.md).
The new checks exercise MPI runtime and native help; dedicated CI also
compares actual MoS₂ serial/two-rank MPI curvature and pair exports.

## Know what each file contains

- Native `KUBO.csv` already contains point Berry curvature in Å² and can
  be plotted as k-space maps or path curves.
- Native `PAIRS.csv` stores energies, k coordinates and interband
  numerators in eV² Å². Python `import-pairs` validates/caches these data;
  `pair-hall` performs occupations/denominators/BZ integration and writes
  conductivity tables in e²/h; `plot_hall.py` draws those finished tables.
- The existing `wavecar-hall` shortcut combines native export, import and
  integration, preserving all intermediate data. It requires a fresh output
  directory. Cached pairs can be reused for μ/T/region scans.
- Matching PROCAR/WAVECAR/OUTCAR inputs support atom, layer, orbital and
  spin character and selected-band projected charge-Hall attribution.

## Compatibility and scope

Numerical kernels, public argument contracts and output schemas are
unchanged from v1.4.0. Native/Python version labels now report 1.4.1.
The [technical report](../TECHNICAL_REPORT.md) ([PDF](../TECHNICAL_REPORT.pdf))
remains the v1.4.0 method edition with the same figures and scientific
results. Current compile and usage instructions are in the guides above.
Canonical momentum remains the direct-WAVECAR baseline; projected
charge-Hall attribution is not conventional spin-current conductivity.
Wannier workflows remain optional supporting tools.

Publication requires the exact source commit's full CI, actual Bi
serial/MPI calculation and both Intel MPI numerical jobs. See the
[validation record](../VALIDATION_1.4.1.md) and [changelog](../../CHANGELOG.md).
