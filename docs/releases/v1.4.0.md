# VASPBERRY 1.4.0 — native workflows and projected transport

**Source release: 25 September 2026.** Use the fixed `v1.4.0` tag for the
commands and examples below. Build the executables locally.

## Download and start

```bash
git clone --branch v1.4.0 --single-branch https://github.com/Infant83/VASPBERRY.git VASPBERRY-1.4.0
cd VASPBERRY-1.4.0
make serial
python3 -m pip install -r requirements-transport.txt
./build/vaspberry --help
python3 tools/vaspberry_kubo.py --version
```

The source ZIP/tar archives on the release page contain the same versioned
source. Large LFS inputs may be pointers; the
[input guide](../../examples/INPUTS.md) gives the verified download commands.
Licensed VASP/POTCAR inputs are supplied by the user.

## Changes since 1.3.0

- **Clear native commands:** `--task chern`, `z2`, `kubo`, `kubo-pairs`,
  `optical`, `spectrum`, `wavefunction` and `velocity`, with explicit input
  aliases and argument validation. The canonical serial executable is
  `build/vaspberry`; legacy short flags and the previous executable name remain.
- **PROCAR character analysis:** matching SOC wavefunctions, raw atom/orbital
  projections and the actual spin frame support arbitrary named layer/atom
  groups and a chosen Cartesian spin axis. Reusable native pairs give
  selected-band projected charge-Hall contributions versus chemical potential,
  temperature and reciprocal-space region. Independent tables and plots
  retain the selected window and projection coverage. This is distinct from
  conventional spin-current conductivity.
- **Reproducible instructions:** a native argument/output reference,
  calculation-to-CSV-to-plot hands-on guide and report-to-example map separate
  drawing saved results, rerunning VASPBERRY and regenerating VASP input.
  A small analytic PROCAR example exercises the general interface without
  proprietary material data.
- **Direct topology comparison:** the report places native MoS₂ Z₂=0 beside
  fresh Bi Z₂=1, with input conditions, original fields and commands. Bi's
  ordinary WAVECAR preparation no longer requires the optional PAW-spin producer.
- **Fixes:** pair export accepts k-dependent occupations; canonical velocity
  output has corrected SI units and extrema indexing; MPI Fukui extrema use
  the gathered mesh; tiny wavefunction grids no longer divide by zero in the
  progress display. Incompatible Z₂ metadata are rejected before plotting.

The separate Kubo curvature kernels retain the standard normalization
introduced in 1.3.0. **Regenerate old `VEL_EXPT*.dat` outputs**: the earlier
velocity diagnostic could print rounded zeros or invalid extrema. Read the
[migration guide](../MIGRATION.md) before combining historical data or local
scripts that apply the old factor-of-two curvature correction.

## Validation and scope

Publication requires successful full CI and actual Bi serial/MPI validation
on the exact release commit, with job-level checks and immutable-tag guards.
The publication record appended below identifies those runs. The
[validation record](../VALIDATION_1.4.0.md) separates new release checks from
historical actual-material calculations.

Canonical momentum is the ordinary WAVECAR route. Full physical velocity
corrections and k/band convergence are separate questions. PROCAR projections
provide state character and a defined projected charge response; they are
not a complete local-current partition or automatically a spin-current Kubo
response. Full-BZ uniform sampling is required for the documented transport
integrals. Rigid-band occupation scans do not recalculate an electronic
structure under doping, strain or electric field.

The optional PAW spin producer excludes Hubbard U. The existing Bi spin-Hall
mesh study remains unconverged, and the MnBi₂Te₄ coarse optical integral is
a diagnostic. These limits do not prevent canonical-momentum and projection
comparisons within their stated scope.

Cite version 1.4.0, the exact source commit and the scientific methods used,
as specified in [CITATION.cff](../../CITATION.cff). The historical V1.0 DOI
does not identify this release.
