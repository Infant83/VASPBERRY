# VASPBERRY agent entry points

For a request to install VASPBERRY for an agent, read
[docs/AGENT_USAGE.md](docs/AGENT_USAGE.md). Install the Codex plugin or the
standalone skill as appropriate for the user's agent. The maintained skill
source is [plugins/vaspberry/skills/vaspberry/SKILL.md](plugins/vaspberry/skills/vaspberry/SKILL.md).

For VASPBERRY calculations or scientific interpretation, read that skill and
the references for the requested observable. Use the selected engine
release's actual commands, input requirements and validation. Record the
source version/commit and distinguish analytic software checks from
convergence and validation of a material result.

The plugin does not supply VASP or licensed VASP inputs. Follow the existing
README citation guidance and retain contributor and third-party notices.
