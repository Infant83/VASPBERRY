# Archived VASP run

These files accompany the tracked Bi `WAVECAR` as provenance evidence. The
run recorded by `OUTCAR` and `vasprun.xml` used VASP 5.4.1 on 2016-06-16,
`ICHARG=11`, a full 12 x 12 x 1 Gamma-centered mesh, SOC spinors, and
`ISYM=-1`.

The preceding SCF inputs and output that produced the input `CHGCAR` are not
available. In addition, `INCAR.unverified` differs from settings recorded in
`OUTCAR`, including `ICHARG` and `PREC`, and is not asserted to be the
provenance of the archived `WAVECAR`. Keep the raw output files unchanged.

For a new calculation, use the reviewed templates in [`../inputs/`](../inputs/).
